# BHH-Insight
Ein RAG-basiertes Assistenzsystem zur intelligenten Erschließung von Hochschuldokumenten

# Einrichtung
Kopiere .env.example zu .env, und fülle deinen OpenAI-Key ein.
Alternativ funktioniert auch, diese variable als `apiKey` oder `adminAPIKey` in der Terminal-Umgebung zu passen.

# Starten

```bash
$ npm run start
```
